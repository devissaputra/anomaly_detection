\begin{abstract}
I train an Isolation Forest on digits 1 through 9 and treat digit 0 as unseen novelty. The project separates anomaly-score ranking from the final thresholded decision.
\end{abstract}

\section{Question}
Can a model trained only on normal digit classes identify digit 0 as unusual?

\section{Data and Method}
I use the scikit-learn digits dataset. Digit 0 is removed from the training data. The Isolation Forest uses 350 trees, contamination 0.10, and random state 42.

\section{Results}
The recorded test results are 0.8119 ROC-AUC and 0.2927 F1 across 629 held-out examples.

\section{Interpretation}
The continuous anomaly score ranks novel examples reasonably well, but the built-in threshold produces much weaker binary decisions.

\section{Limitations}
Only one digit is used as the novelty class. A stronger study would test every digit, tune the threshold on validation data, and compare other novelty-detection methods.

\section{Reproduction}
Install \texttt{requirements.txt} and run \texttt{python src/run\_experiment.py}.
